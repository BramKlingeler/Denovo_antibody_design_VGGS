# Denovo_antibody_design_VGGS
This repository contains both adapted methods of GGS (https://github.com/kirjner/GGS) and dWJS (https://github.com/prescient-design/walk-jump) which have been used as a basis for my Msc thesis of System and Control at TUDelft

The main goal for my Thesis is to maximize diversity and novelty of the final sampling output to see if the max fitness can be increased for de novo antibody design. Hereby diversity is the main target of interest to achieve sequences with high fitness and diversity.
