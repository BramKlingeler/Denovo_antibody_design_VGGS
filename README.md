# Denovo_antibody_design_VGGS
This repository contains both adapted methods of Gibbs sampling with Graph-based Smoothing (GGS, https://github.com/kirjner/GGS), which we introduce as Varying length Gibbs sampling with Graph-based Smoothing and discrete Walk and Jump Sampling (dWJS, https://github.com/prescient-design/walk-jump) which have been used as a basis for my Msc thesis of System and Control at TUDelft.

The main goal of this Thesis is to maximize diversity and novelty of the sampled outputs to see if the max fitness can be increased for de novo antibody design. Hereby diversity is the main target of interest to achieve sequences with high fitness and diversity. There are two novel improvements introduced in this thesis. First, GGS is trained on antibody data provided by the Observed Antibody Space (https://opig.stats.ox.ac.uk/webapps/oas/) and specifally data from the research Jaffe et al for all relating to the disease SARS-CoV-2. Prior work has only performed designing tasks for Green Fluorescence Protein (GFP) and Adeno Associated Virus (AAV). Second, we introduce a method known as gap token alignment to the data and model. Fitness landscapes can only be represented by fixed length sequences, however the dataset set from Jaffe et al. contains an array of varying length sequences. Gap tokens are a "-" token that increase the vocabulary size by 1 as defined by FASTA encoding. Using gap tokens sequences of shorter length can be enlarged such that all sequences in the dataset contain the same length. Gap token alignment is done with ANARCI and the scheme is AHo alignment.
